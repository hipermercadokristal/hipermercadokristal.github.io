CRYSTAL SOFTWARE

Importar inventario

Carga Excel o CSV con código de barras, descripción, departamento/categoría y precios USD/VES. El stock es opcional; si falta o está vacío, no se controla. Si la descripción termina en un peso o contenido como “500g”, se guardará en Presentación. Se actualiza primero por código de barras y luego por nombre/presentación normalizados, con coincidencia aproximada prudente para nombres casi iguales. Las filas repetidas del archivo se consolidan usando la última aparición; las variantes de tamaño buscan primero una foto de nombre igual o muy parecido en su categoría y, si no hay, en el catálogo completo cuando la coincidencia es clara. Los duplicados exactos anteriores se archivan conservando el historial de pedidos. Primero revisa la vista previa.
